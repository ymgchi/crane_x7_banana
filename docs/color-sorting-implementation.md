# 色分別キューブ仕分けデモの実装

このドキュメントでは、C++で実装された色分別デモ `color_sorting` の実装について解説します。

## アーキテクチャ

C++のみで実装されたシンプルなアーキテクチャを採用:

```
┌─────────────────────────────────────────────────────────────┐
│                    color_sorting node (C++)                  │
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────────┐ │
│  │  色検出         │  │  座標変換       │  │ モーション   │ │
│  │  (OpenCV HSV)   │  │  (TF2)          │  │ (MoveIt)     │ │
│  └─────────────────┘  └─────────────────┘  └──────────────┘ │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
                    MoveGroupInterface
                            │
                            ▼
                      Robot / Gazebo
```

## 動作フロー

### 2フェーズ構成

**フェーズ1: バッチスキャン**
1. カメラ観測姿勢へ移動（上から見下ろす位置）
2. RGB画像からHSV色検出で全キューブを検出
3. 作業エリア内のキューブをフィルタリング
4. 重複検出を除去（4cm以内は同一物体）
5. ターゲットキューをビルド

**フェーズ2: ピック＆プレース**

各ターゲットに対して:
1. **ホバー**: 目標上空（0.20m）へ移動
2. **再検出**: 5回測定の平均で位置精度向上（200ms間隔）
3. **下降**: 動的ピック高さ（detected_z - 0.005m）
4. **把持**: グリッパーを閉じる（20°）
5. **上昇**: 0.30mまで持ち上げ（衝突回避）
6. **移動**: 色に対応した配置場所へ
7. **解放**: グリッパーを開く（60°）
8. **復帰**: カメラ観測姿勢に戻る

## 色検出システム

### HSV色空間による検出

OpenCVの`cv::inRange()`を使用してHSV色空間で色検出を行います。

**検出色とHSV範囲:**

| 色 | H (色相) | S (彩度) | V (明度) | 配置場所 |
|---|---|---|---|---|
| **オレンジ** | 100-125 | 100-255 | 30-255 | 右奥 (0.30, -0.30) |
| **黄** | 20-35 | 100-255 | 60-255 | 左奥 (0.30, 0.30) |
| **緑** | 40-80 | 100-255 | 30-255 | 前方 (0.45, 0.00) |

### ノイズ除去（モルフォロジー変換）

```cpp
// ノイズ除去処理
cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel_7x7);   // 小さいノイズを除去
cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel_7x7);  // 穴を埋める
cv::erode(mask, mask, kernel_3x3);                          // 隣接物体を分離
```

## 座標変換

### TF2による変換

カメラ座標系からロボットベース座標系への変換にTF2を使用します。

**処理フロー:**
1. RGB画像から色検出でピクセル座標を取得
2. 深度画像から対応するピクセルの深度値を取得（5x5メディアンフィルタ）
3. カメラモデル（`image_geometry::PinholeCameraModel`）でピクセル+深度→3D点に変換
4. TF2で`camera_color_optical_frame`→`base_link`に座標変換

**TFフレーム候補（名前空間対応）:**

```cpp
// ソースフレーム（カメラ）
{"camera_color_optical_frame", "camera_depth_optical_frame", "camera_link"}

// ターゲットフレーム（ロボットベース）
{"base_link", "crane_x7/base_link", "crane_x7_mounting_plate"}
```

### 深度補正

```cpp
const double DEPTH_OFFSET = 0.015;  // カメラ測定値の補正（経験値）
depth_corrected = raw_depth + DEPTH_OFFSET;
```

## パラメータ設定

### 検出パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| `DUPLICATE_DETECTION_THRESHOLD` | 0.04m | 同一物体判定距離 |
| `DEPTH_OFFSET` | 0.015m | 深度補正値 |
| `DEPTH_MIN` | 0.15m | 有効深度範囲（最小） |
| `DEPTH_MAX` | 1.2m | 有効深度範囲（最大） |
| `MAX_TOTAL_OBJECTS` | 10 | 安全制限（無限ループ防止） |

### モーションパラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| `PICK_Z_OFFSET` | 0.005m | 検出Zからのオフセット |
| `PICK_Z_ABOVE` | 0.20m | ホバー高さ |
| `PICK_Z_LIFT` | 0.30m | 持ち上げ高さ |
| `GRIPPER_OPEN` | 60.0° | グリッパー開放角度 |
| `GRIPPER_CLOSE` | 20.0° | グリッパー把持角度 |
| `MAX_GRIPPER_YAW` | 45.0° | グリッパー最大回転角 |

### MoveIt設定

| パラメータ | 値 |
|-----------|-----|
| 速度スケール | 0.7 |
| 加速度スケール | 0.7 |
| プランニング時間 | 20秒 |
| リプランニング | 有効 |

## 作業エリア

検出されたオブジェクトは以下の範囲内のみ処理されます:

```
X: 0.00 〜 0.50 m（前方）
Y: -0.40 〜 0.40 m（左右）
Z: > -0.20 m（テーブル面より上）
```

## トラブルシューティング

### キューブが検出されない

1. HSV範囲が環境照明に合っているか確認
2. 深度画像の取得を確認: `ros2 topic echo /camera/aligned_depth_to_color/image_raw`
3. TFフレームを確認: `ros2 run tf2_tools view_frames`

### ピック位置がずれる

1. `DEPTH_OFFSET`値を調整
2. カメラキャリブレーションを確認
3. TF変換が正しく行われているか確認

### グリッパーで掴めない

1. ピック高さを調整（`PICK_Z_OFFSET`）
2. グリッパー閉じ角度を調整（`GRIPPER_CLOSE`）
3. キューブのサイズを確認
